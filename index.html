Hermes Personal Assistant

A private, single-user assistant that runs on its owner's own computer. It uses Google APIs only to back up its own configuration files to the owner's Google Drive and to help the owner with their own Gmail, Calendar, Docs and Sheets.

一個只供擁有者本人使用、喺佢自己電腦上運行嘅私人助理。佢只會用 Google API 將自己嘅設定檔備份去擁有者嘅 Google Drive，以及協助擁有者處理佢自己嘅 Gmail、日曆、文件同試算表。

This application is not offered to the public.
此應用程式不對外提供。
